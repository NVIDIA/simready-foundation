# Robot Materials

Robot materials defines material organization requirements for robot assets in Isaac Sim environments.

:::{warning}
These requirements belong to the deprecated `CAP023_RobotMaterials.Isaac`, which
`Robot-Body` `2.0.0` through `3.1.0` select as optional and `Robot-Body` `4.0.0` leaves out.
:::
