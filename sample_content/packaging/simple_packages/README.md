# Simple sample packages

These five self-contained package examples use `Apache-2.0` declarations and
current validation receipts. The USD examples are static snapshots of the
canonical apple and orange assets, with their default variants composed,
instances expanded, and dependencies copied into each package.

## Rebuilding

Use Python 3.12 with `simready-package` 2026.10 or newer,
`simready-validate[usd]`, `blake3`, and this checkout's Core, Newton, and Sensors
tiers installed. From the repository root, build into a new staging directory:

```bash
python nv_core/package_sample/create_sample_packages.py .tmp/simple-packages
```

The script validates the source snapshots, builds package definitions and BOMs,
verifies hashes, and runs package post-validation. It preserves the canonical
assets. Copy the five validated output folders here to update the fixtures.
Validation timestamps are generated by the installed validator. The local
`.gitattributes` preserves package bytes across checkouts so newline conversion
cannot invalidate hashes.

| Folder | Contents | Expected package validation |
|---|---|---|
| `apple_a01_materials/` | Materials and textures; SHA-256 BOM | `Package@1.0.0` passes |
| `apple_a01_nobom/` | Apple USD; minimal definition without a BOM | `Package-NoBOM@1.0.0` passes; `Package@1.0.0` fails its BOM-dependent checks |
| `apple_a01_usd_bom/` | Apple USD; SHA-256 BOM and pre-validation evidence | `Package@1.0.0` passes |
| `apple_a01_usd_bom_multi_hash/` | Apple USD; SHA-256 and BLAKE3 hashes | `Package@1.0.0` passes |
| `fruit_f01_multi_usd/` | Apple and orange USDs; SHA-256 BOM and pre-validation evidence | `Package@1.0.0` passes |

Each packaged root USD passes `Robotics-Prop@3.2.0` and
`Robotics-Prop@4.0.0`. Package construction also checks
`Package-Candidate@1.0.0`. Receipts retain individual optional-feature results;
a profile pass does not imply that every optional feature passed.

## Thumbnails and evidence

The builder copies each canonical asset's real thumbnail from
`.thumbs/256x256/<filename>.usd.png`. A missing thumbnail stops the build.

BOM-bearing USD packages register the BOM, Package-Candidate conformance, and
root-USD list in `metadata[]`. Post-validation evidence is stored separately
under `.metadata/` and is outside the package hash. The no-BOM example keeps
its minimal definition so it remains useful for exercising missing-BOM checks.
