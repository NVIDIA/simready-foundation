# Feature: `FET006_Materials.Openpbr`

| **Property**            | **Value**         |
|-------------------------|-------------------|
| Contract                | `FET006_Materials.Openpbr` |
| Runtime                 | `Openpbr` |
| Proprietary Techs       | `None` |
| Versions                | `0-1-0`, `0-2-0` |

## Description

Defines the OpenPBR material contract. The final surface is authored as an OpenPBR shading network
on `outputs:mtlx:surface`, so the asset renders in RTX and perception runtimes without a
vendor-specific material. `VM.PBR.001` accepts only an OpenPBR surface on
`outputs:mtlx:surface`. A material whose only final surface is MDL satisfies
`FET006_Materials.MDL` instead; a profile that accepts either selects both. The
UsdPreviewSurface preview is a separate feature (`FET006_Materials`); profiles that
require both list both.

Whether renderable geometry resolves a material (`VM.MAT.001`) is
[`FET009_MaterialCoverage`](FET009_MaterialCoverage.md)'s
requirement from version `0-2-0` of this feature. An asset with geometry selects both; a
material published on its own selects this feature without it.

## Dependency Graph

This feature has no dependencies and no other features depend on it directly. Each version
names a `FET006_Materials` version as its `source_feature`: `0-1-0` names
`FET006_Materials.0-1-0`, and `0-2-0` names `FET006_Materials.0-3-0`. The
link classifies this feature as a runtime variant of that source; it does not make the source
feature validate.

## Use Cases

Products or workflows that consume this feature:

- SimReady validation verifies OpenPBR surface output, parameter ranges, MaterialX graph structure,
  shader input types, material binding, texture colour space, and texture size requirements.
- `simready-foundation-conform-fet-006-openpbr` authors an OpenPBR surface from a material's
  UsdPreviewSurface or MDL surface and leaves the existing surfaces in place.

## Adapters

| From Feature | To Feature | Adapter | Status | Notes |
|--------------|------------|---------|--------|-------|
| `FET006_Materials.0-1-0` | `FET006_Materials.Openpbr.0-1-0` | `nv_core/cip_specs/asset_handler_modules/neutral_to_openpbr` | Done | Authors an OpenPBR surface on `outputs:mtlx:surface`, reading the material's UsdPreviewSurface preview for base colour, roughness, metalness and normal. Reconnects texture-driven channels as `tiledimage` readers instead of flattening them to constants. |
| `FET006_Materials.MDL.0-1-0` | `FET006_Materials.Openpbr.0-1-0` | `nv_core/cip_specs/asset_handler_modules/neutral_to_openpbr` | Done | Same adapter and the same output. Where a material has an OmniPBR or OmniGlass MDL shader, that source takes precedence over the preview surface, since it holds the higher-fidelity values. |
| `FET006_Materials.0-3-0` | `FET006_Materials.Openpbr.0-2-0` | `nv_core/cip_specs/asset_handler_modules/neutral_to_openpbr` | Done | Same adapter and the same output. |
| `FET006_Materials.MDL.0-3-0` | `FET006_Materials.Openpbr.0-2-0` | `nv_core/cip_specs/asset_handler_modules/neutral_to_openpbr` | Done | Same adapter and the same output. |

All four entry points share one implementation, which reads whichever source surface a
material provides. They are declared separately so the registry can resolve a path from each
starting feature. The adapter runs in Kit; `simready-foundation-conform-fet-006-openpbr` runs
the same migration without it.
