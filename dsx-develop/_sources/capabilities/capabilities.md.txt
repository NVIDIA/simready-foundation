# Capabilities

This section lists the capabilities from every SimReady Foundation
[tier](../guides/tiers.md) together. A capability is a static contract: a
requirement bundle with no runtime tests. The **Runtime** column is the
runtime a variant targets, which is independent of the tier that owns the
contract.
