## Description

Defines the Isaac Sim composition contract. Assets organize files, payloads, and prims in the Isaac Sim asset-structure pattern for predictable runtime loading and physics composition.

## Pipelines

Source file type:

- `.usd`, `.usda`, `.usdc`, package source folder, or package root as applicable.

Validation or runtime pipeline:

- SimReady validation verifies the selected CAP100_IsaacComposition.Isaac manifest.
- Isaac Sim import/runtime checks verify composed asset structure.
- Version 0-4-0 composition is generated by public
  `isaacsim-asset-isolated==6.2.0.1`; the optional tier-core `[isaac]` extra also installs
  `isaacsim-robot-schema==6.2.0.0`. Profiles, the CLI, SimReady-specific rules,
  and small guarded temporary transformer patches are supplied by
  `simready.asset_transformer`
  (`nv_core/tiers/simready_foundation_tier_core/tools/isaac_asset_transformer`) via the
  `simready_physx_to_isaac_prop` transform. Python 3.12 is required; both Isaac
  packages install from PyPI with `pip install "simready-foundation-tier-core[isaac]"`.
