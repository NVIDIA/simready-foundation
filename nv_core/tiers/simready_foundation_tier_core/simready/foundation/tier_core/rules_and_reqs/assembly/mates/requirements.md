# Requirements

## Summary

Mate sites mark pairing faces on an asset. Discovery is the authored `simready:mate:domain` and `simready:mate:role` attributes on an `Xform`. Prim names are unconstrained. The `mechanical:` rules below apply to sites whose `domain` is `mechanical`; other domains are discovered but not governed here.
