# Newton Tier

The `simready-foundation-tier-newton` package contains the Newton-solver physics
requirements, their validators, and the Newton runtime features.

## Independence

This tier is **independent of the Core tier at the package level**: it declares
no dependency on `simready-foundation-tier-core` and imports no Core Python code
(the few shared validator helpers are duplicated locally). Its features reference
Core requirement and capability IDs (`RB.*`, `JT.*`, `RV.*`,
`CAP000_Core`, `CAP024_BaseArticulation`) purely as **runtime
content**, resolved from the merged
registry when both tiers are installed. Core installs Newton automatically.
For full validation of a robot/prop profile's Newton gates, install Core:

```bash
pip install simready-validate simready-foundation-tier-core
```

## Requirements

The Newton tier contributes Newton-solver requirements to the shared
physics-bodies capabilities; the base requirements in those capabilities remain
Core-owned.

| Code | Capability | Validator |
| --- | --- | --- |
| `NEWTON.BA.001` | base_articulation | `NewtonArticulationRootConfig` |
| `NEWTON.DJ.001` | physics_driven_joints | `NewtonJointDriveAPIChecker` |
| `NEWTON.DJ.002` | physics_driven_joints | `NewtonJointAttributesChecker` |
| `NEWTON.DJ.003` | physics_driven_joints | `NewtonMimicAPIChecker` |
| `NEWTON.MAT.001` | physics_materials | `NewtonMaterialAttributesChecker` |
| `NEWTON.COL.001` | physics_rigid_bodies | `NewtonColliderAPIChecker` |
| `NEWTON.COL.002` | physics_rigid_bodies | `NewtonSDFAttributesChecker` |
| `NEWTON.MAS.001` | physics_rigid_bodies | `NewtonMassAttributesChecker` |

The Newton runtime-variant scaffolding requirements (`RV.004`-`RV.006`) and the
cross-runtime purity/isolation requirements (`RV.010`-`RV.011`) remain owned by
the Core `runtime_variants` capability.
