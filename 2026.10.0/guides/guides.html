End to End Guides#

End to end workflow guides which cover the entire process of creating USD assets with various capabilities.

Foundations 2 uses CAP-prefixed static capabilities, dotted runtime-tested feature IDs, wildcard profile selectors, optional feature/capability selectors, and caller-supplied multi-profile validation targets. A testless contract is a FET only when it is the source of tested derived FETs; otherwise it is a capability. The feature, adapter, profile, and validation guides define that contract.
