# Requirements

## Summary

**ROS Bridge** requirements check that an Isaac Sim stage authors OmniGraph ROS 2
bridge nodes so external ROS 2 systems can communicate with the simulation.

## Schema / OpenUSD Specification

OmniGraph nodes are authored as USD prims (commonly type `OmniGraphNode`) with a
`node:type` token identifying the registered OmniGraph node type.
