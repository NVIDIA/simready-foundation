# Requirements

## Summary

**Smoke** provides a minimal stage readiness check so a new additive tier can
register and validate at least one requirement.

This capability ensures:
- **The stage must declare a valid `defaultPrim`**

## Schema / OpenUSD Specification

Smoke utilizes the following USD concepts that are part of the core OpenUSD
specification:

- [UsdStage defaultPrim](https://openusd.org/release/api/class_usd_stage.html)
