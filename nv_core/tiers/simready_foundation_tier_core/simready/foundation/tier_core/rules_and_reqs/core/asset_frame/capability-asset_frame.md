# Asset Frame

Asset Frame (AF) declares an asset's semantic front in local coordinates. It
supports intentional placement and orientation without guessing from geometry.

`FET008_ObjectForward.0-1-0` owns AF.001 directly. AssetFrameChecker is its sole
validator. Assets without a semantic front need not select this feature.
Semantic correctness of the chosen front requires author review.
