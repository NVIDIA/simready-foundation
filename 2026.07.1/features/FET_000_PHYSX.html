Feature: FET_000_PHYSX#

Property

Value

Feature Name

FET_000_PHYSX

Runtime

PHYSX

Proprietary Techs

PhysX

Latest Version

0.1.0

Description#

The Core (PhysX) feature adds the PhysX physics runtime variant to a SimReady asset on top of the neutral Core contract. A satisfying asset exposes a PhysX variant set on its root that, when enabled, composes a PhysX runtime payload from runnables/physics/physx.usd, while the neutral asset stays unchanged when the variant is disabled.

This feature only deals with the PhysX runtime variant. Newton and MuJoCo variants are provided by FET_000_NEWTON and FET_000_MUJOCO.

Use Cases#

  • Assets that must run under the PhysX solver while remaining valid as a neutral SimReady asset.

  • Pipelines that switch an asset into PhysX by selecting a single variant.
